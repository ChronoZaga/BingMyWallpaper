# BingMyWallpaper

Run the EXE and it will download the Bing Wallpaper of the day in 4K resolution to your temp directory, and set it as your Windows wallpaper.

Run the EXE with an argument of a number (1-7) of days prior ("C:\users\yourname\desktop\BingMyWallpaper.exe 1"), and it will use the Bing wallpaper from that many days back.

Run the EXE with an argument of DL ("C:\users\yourname\desktop\BingMyWallpaper.exe DL"), and it will download the Bing wallpapers from the last 7 days in 4K resolution to your desktop.
